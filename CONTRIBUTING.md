# Contributing

Thanks for your interest in improving Walking Map.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Run a quick local check in the browser.
5. Open a pull request with a clear description.

## Project goals

This project is a prototype for visualizing walkability and station accessibility. Contributions should stay aligned with that goal.

## Good contribution ideas

- Better map labeling
- Improved walking radius logic
- Better mobile responsiveness
- Additional city datasets
- UX improvements for station selection and filtering

## Code style

- Keep the project simple and lightweight.
- Prefer clear, readable JavaScript.
- Avoid unnecessary dependencies.
- Keep the map UI usable and accessible.
