# Release Notes

## v1.0.0

### Highlights
- Initial public release of Walking Map
- Tokyo station data loaded on a Leaflet-based map
- Search and selection for train stations
- Walking radius visualization for selected stations
- Demo mode with approximate area and ORS API support
- Improved labels and map filters for better usability
- GitHub Pages demo and public GitHub repository setup

### Included
- Interactive station exploration
- Walking access analysis by radius
- Landmark markers for major Tokyo neighborhoods
- Mobile-friendly panel layout
- Clear documentation and repository structure

### Notes
- This is a prototype focused on concept validation and UI demonstration.
- Real walking result quality depends on ORS API data and key configuration.
- The current version is best suited for demo, brainstorming, and early-stage urban accessibility exploration.
